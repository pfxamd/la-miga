# LA MIGA — Obrador photographic series

Six original generated editorial photos that depict bread-making scenes, not photographs of a confirmed operating location.

| File | Contents |
| --- | --- |
| `hero.webp` | Panoramic workshop, bread, baskets and oven |
| `amasadora.webp` | Mixer and dough |
| `fermentacion.webp` | Proofing baskets and dough |
| `banco.webp` | Workbench and tools |
| `formado.webp` | Hands scoring dough, no face |
| `horno.webp` | Baked loaves at the oven |

All files live under `public/assets/obrador/`. See `src/pages/obrador/index.astro` for their placements and descriptive alternative text. Photography uses consistent warm light, flour, linen, wood and metal. PhotoSwipe is enabled only on this page using the existing helper.

# LA MIGA

Modern artisan bread bakery storefront concept based in Tétouan, Morocco.

Stack: Astro (static), TypeScript, Preact islands, Nano Stores (persistent shopping cart), custom CSS, GitHub Pages.

Ordering flow: bread catalog → cart → WhatsApp pre-filled order. No payment gateway or backend.

Product images and visual identity are original LA MIGA assets.

## Development

```bash
npm install
npm run dev
npm run build
```

GitHub Pages path: `/la-miga/`.

The site is currently in its initial setup phase.
